# HPM (Hyperpower Program Manager)

A lightweight, command-line Wine/Proton application launcher for Linux.

## Commands

```text
add    -> append application to config file
remove -> remove application from config file
list   -> list applications in config file
run    -> list applications from the config file and the [appsPath] directory then run them
conf   -> view and edit the configuration file
cls    -> clear the terminal
exit   -> nothing
help   -> big bloack of text
!c     -> cancel any action
```
